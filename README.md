# K-LINE

纯 HTML / CSS / JavaScript 音频可视化，提供两个 K 线版本，默认监控扬声器 / 系统音频。

## 运行

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

打开 <http://localhost:8080>。点击「连接扬声器」，在浏览器选择器中选择屏幕或正在播放声音的标签页，勾选「共享音频」。浏览器要求每次手动连接；具体支持取决于浏览器、系统和所选来源。若没有音频轨道，会提示重新选择。

也可以通过音源下拉框选择内置试听或本地音频，或直接拖入文件。本地文件和试听可直接通过 `index.html` 离线打开，无需安装依赖；文件大小上限 150 MB，格式支持由浏览器决定。

## 两个版本

- **走势 K 线**：时间为横轴。浮点采样、自适应响度归一化与平方根映射增强较低响度的表现；响度和频谱变化驱动走势，可调节声音驱动的随机扰动与影线。进入静音阈值后从上一收盘在 2 秒内逐步跌到指数谷底 200，持续静音时保持谷底直线，不生成随机波动；声音在缓冲期内恢复会立即结束下跌，并从当前位置继续走势。默认低响度增强 4×、随机波动 80%。这些是视觉设置，不改变声音。
- **频响 K 线**：仅显示 100 Hz 至 16 kHz，80 个频段。100–500 Hz 占 40 根及一半横轴空间，500 Hz–4 kHz 占 24 根，4–16 kHz 占 16 根，各区域采用对数刻度。FFT 大小为 16384，兼顾低频分辨率与响应速度。直接读取频谱 dB，在 2–8 kHz 间逐渐增加高频视觉补偿，8 kHz 以上最高 +6 dB，再以显示范围内峰值归一到 0 dB；整体响度变化不参与曲线涨跌，不叠加随机扰动。每根 K 线开盘接上一频段的收盘，每次分析当前频段中心的响应并实时刷新曲线，提供 0–90% 平滑度，默认 30% 以减轻快速抖动；0% 直接显示当前采样值，不等待刷新周期。影线包含当前频段的峰谷及开收值；所有频段仅在绘制时把实体外的上、下影线各限制到 3 dB；只截短超出阈值的部分，较短影线和实体保持原值，悬停仍显示完整实测极值。细线连接按所选平滑度处理的收盘值形成曲线。完全静音时立即显示绘图区垂直居中的水平直线，不保留平滑拖尾或影线；该直线是视觉停靠位置，不代表实测 dB，极低响度但仍有信号时继续显示频谱。纵轴显示相对 dB，范围 -96 至 +3。这里沿频率而非时间构造开、高、低、收，是频谱的 K 线表达，并非金融行情或扬声器设备的校准频响。

频响版本也可直接打开 <http://localhost:8080/index.html?view=frequency>。切换版本会保留当前音源和连接。走势版支持平滑度和 100 / 250 / 500 ms 采样周期；频响版实时刷新，保留平滑度调节（默认 30%），隐藏周期控件；两个版本各自保留平滑度设置。两个版本均支持悬停查看数值和全屏。空格开始 / 停止或播放 / 暂停。高频补偿只作用于显示，不改变播放声音。

页面只保留音源、模式、画布和调节控件，移除侧栏、资料库、宣传文案、BPM 卡片、配色面板、能量量柱与导出弹窗。

## 系统音频

系统音频通过 `getDisplayMedia()` 获取。该 API 要求一并建立视频轨道；页面只分析音频，不显示、录制或上传画面，也不重复回放系统声音。停止、切换音源、结束共享或关闭页面时会释放全部共享轨道。系统音量在设备中调节，文件和试听的音量可在页面中调节。

参考：[MDN getDisplayMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getDisplayMedia)、[Chrome 屏幕共享控制](https://developer.chrome.com/docs/web-platform/screen-sharing-controls)。

## 验证

```powershell
node --test tests/audio-lifecycle.test.cjs tests/signal.test.cjs
```

测试覆盖系统音频连接和资源释放、模式切换不中断捕获、低响度波动、随机强度、静音门限、频率定位、开收连续性、频段峰谷、频率裁剪、低频密度、高频补偿、整体响度无关性、实时响应及全频段影线显示阈值。设备测试使用模拟媒体流，不申请实际共享权限。

## 文件

- `index.html` / `styles.css`：精简界面与响应式布局。
- `app.js`：音频来源、Canvas 绘图与交互。
- `signal.js`：自适应响度、随机走势和对数频谱映射。
